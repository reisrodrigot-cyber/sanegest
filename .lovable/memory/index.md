# Project Memory

## Core
SaneGest — sistema de gestão de obras de saneamento. Paleta: azuis #0C447C/#185FA5, cinzas #888780/#D3D1C7. Inter font. PT-BR only.
6 roles: admin, gerencia, sala_tecnica, almoxarifado, encarregado, topografo. Status OS: VERMELHO→AMARELO→VERDE.
Lovable Cloud enabled (Supabase). Auth via Supabase Auth (email/password). Admin has view-as selector.
